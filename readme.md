## よく使うテンプレートとか
#### 宣言代入系
* `let(N)`  
元は`ll N;cin>>N`である。整数型の宣言と代入を同時に行える。
* `mlet(a1,a2,...)`  
`let()`マクロの可変長引数にしたバージョン。複数個の変数宣言と代入を行える。
* `letv(A,N)`  
長さ`N`の`vector<ll> A`を宣言して各要素に代入ができる。問題で  
$A_1,A_2,\ldots,A_N$と横向きに入力が与えられた場合の宣言と入力ができる。
#### それ以外
* `printv(V,c)`  
vectorやsetなどの中身を出力する。要素間の仕切りとして`c`が入る。一番最後には`c`が入らないようにしている。
* `bye(a)` (面白いので拝借させていただきました。)  
元は`cout<<a<<el;return 0`である。`a`を出力して即終了できる。
* `ff`と`ss`  
それぞれ`first`と`second`を意味する。いつまでたってもfirstやsecondを誤字るので作った。
